# 美食景點整理專案底層架構原則 (PROJECT_RULES.md)

本檔案為本專案不可違背之底層架構規範，所有操作與腳本開發皆必須嚴格遵守：

## 1. 雲端硬碟同步已全面取消且永久停用
- **嚴禁**建立、啟用或維護任何向 Google Drive（如 `~/Library/CloudStorage/GoogleDrive-...`）或 Apple iCloud Drive（`~/Library/Mobile Documents/...`）的檔案複製、同步腳本或 macOS LaunchAgent 監控服務。
- **嚴禁**在背景常駐執行定時同步行程或輪詢。

## 2. 嚴格防商業水軍、店家自薦與同行互捧審查機制（Anti-Astroturfing & Anti-Promo Protocol）
- **禁止盲信社群單一捧場**：社群（特別是 Threads、Dcard、IG）留言中常見「店家本尊開小帳自薦」、「同行親友互相 @ 留言拉抬聲量」或「網紅打卡擺拍」。
- **收錄篩選準則**：
  1. **拒絕大型連鎖集團與粗飽批發店**：如一般平價批發小火鍋、連鎖網美咖啡廳等非在地獨立私房店，一律剔除，維持精選純度。
  2. **辨識店家自吹與親友團**：凡發現店家官方帳號親自留言或好友互捧拉抬者，必須全面檢視 Google 1～3 星真實負評與 PTT 鄉民評價。
  3. **批判性避雷無情揭露**：若經評估保留，必須在店家卡片之 `tips`（避雷重點）中明確標示【⚠️ 社群自介與親友互捧預警】，具體揭露「網美溢價」、「排隊時間成本過高」、「口味偏淡/偏鹹」、「份量過少」或「出餐過慢」等真實缺點，杜絕盲目造神。

## 3. 踩雷大賽反向對照數據庫（Negative Control Blacklist）
- **資料庫路徑**：`data/blacklist_avoidance_database.json`
- **數據來源**：Threads「台南第一屆難吃到不會再去的餐廳大賽」等真實老饕差評集合（涵蓋億哥、香圃、牛室、福爾摩沙Buffet、鼎富發、壓克力寶寶系列等 18 間公認雷店）。
- **強制比對原則**：任何新抓取之店家資料，在併入正式手冊前必須強制執行 `scripts/verify_blacklist.py` 進行黑名單比對。凡命中者一律禁止收錄為推薦名單，確保隨身手冊公信力。

## 4. 發布與傳播渠道（雙軌制）
- **軌道一：本地單檔離線優先**
  - 所有手冊產出物（如《美食避雷隨身手冊.html》、《全台看海放空旅宿隨身手冊.html》）必須為 **100% 預渲染、內嵌 Inline CSS、零外部 CDN 依賴** 的純前端 HTML 單檔。
  - 支援 AirDrop、社群通訊軟體分享或在手機檔案中直接離線打開。
- **軌道二：GitHub Pages 靜態網站 (PWA)**
  - 靜態網站包統一存放於 `web_dist/`。
  - 透過 `scripts/deploy_web.py` 一鍵重新建置雙手冊並推送至 GitHub 儲存庫（`cieaerg-dotcom/food-guide`），觸發 GitHub Actions 線上部署。
